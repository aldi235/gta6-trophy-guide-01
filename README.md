Leonida Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5. Every trophy shows its official name, description and grade, a guide written for this entry that names the sources each fact came from, and flags for missable and hidden trophies. It also gives a six-stage roadmap to the platinum (story first, then side content, then the 100% checklist, then cleanup), a checklist that saves progress in the browser with export and import, filters by kind and grade, and a spoiler setting that hides story trophies until they are earned. Static files under `app/`, no build step, no network requests at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
